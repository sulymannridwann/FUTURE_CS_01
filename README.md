# 🛡️ OWASP Juice Shop – Security Assessment Report

This project presents a real-world web application vulnerability assessment conducted using **OWASP ZAP** on **OWASP Juice Shop**. It was completed as part of the **Future Intern Cybersecurity Internship Program**.


---

## 📌 Project Overview

The aim of this assessment was to identify and analyze common web application vulnerabilities and map them to the [OWASP Top 10](https://owasp.org/www-project-top-ten/).

## ⚠️ Vulnerabilities Identified

| Vulnerability                        | Severity  | OWASP Category           |
|-------------------------------------|-----------|---------------------------|
| Cross-Domain Misconfiguration       | Medium    | A5:2021 – Security Misconfig |
| Private IP Disclosure               | Low       | A6:2021 – Vulnerable & Outdated Components |
| Cloud Metadata Potentially Exposed  | High      | A5:2021 – Security Misconfig |
| SQL Injection                       | High      | A1:2021 – Broken Access Control |
| Missing Anti-CSRF Tokens           | Medium    | A8:2021 – Software & Data Integrity Failures |

---

## 📝 Methodology

1. Deployed OWASP Juice Shop locally.
2. Scanned the application using **OWASP ZAP**.
3. Identified real-world vulnerabilities and mapped them to OWASP Top 10.
4. Documented each issue with:
   - Description
   - Screenshot
   - Risk Impact
   - Remediation Recommendation
